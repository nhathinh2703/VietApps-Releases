# 🚀 VietApps - Trung tâm Phát hành & Cập nhật Phần mềm Giáo dục

Kho lưu trữ công khai (Public Release Hub) cung cấp siêu dữ liệu cập nhật tự động (Metadata) và bộ cài đặt chính thức cho toàn bộ hệ sinh thái phần mềm **VietApps** phục vụ Giáo dục Việt Nam:

- **✨ VietMix**: Phần mềm Chuẩn hóa & Trộn đề thi GDPT 2018 (Word + Excel).
- **📝 VietTest**: Hệ thống Kiểm tra & Đánh giá năng lực học sinh.
- **🛠️ VietFix**: Bộ công cụ chuẩn hóa & sửa lỗi văn bản Word đề thi.
- **📚 VietBook**: Nền tảng biên soạn giáo trình và tài liệu thông minh.
